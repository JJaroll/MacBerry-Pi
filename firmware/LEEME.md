# Firmware

Código original de **qbancoffee (Rocky Hill)**, [`imac_g3_ivad_board_init`](https://github.com/qbancoffee/imac_g3_ivad_board_init), LGPL-3.0. Incluido sin modificar.

| Ruta | Contenido |
|---|---|
| `imacG3IvadInit/` | Sketch de Arduino que inicializa la placa IVAD por I²C (`.ino`, `.h`, `ivad.h`) y `useful_code_and_notes.txt` |
| `edidSimulator/` | Sketch de Arduino que emula la memoria EDID del monitor |
| `init_ivad.py` | Misma inicialización I²C desde una Raspberry Pi (Python) |
| `edid.bin` | EDID del iMac G3 |

Las traducciones de los LEEME del proyecto original están en [`../docs/traducciones/`](../docs/traducciones/).
