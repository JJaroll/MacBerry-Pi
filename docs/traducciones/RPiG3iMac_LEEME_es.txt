
Estas placas fueron creadas y generosamente aportadas por Rudy https://reng.ca para
este proyecto para que otros las utilicen.

RPiG3iMac       Contiene los archivos de proyecto de KiCad para un HAT de Raspberry Pi
                con LEDs de encendido y actividad. El HAT también convierte la
                señal TTL RS232 entrante a niveles CMOS para su uso por el
                puerto serie integrado.
            
RPiG3iMacJ20    Contiene los archivos de proyecto de KiCad para una placa adaptadora
                para las tiras de pines J3 y J5 en la placa J20. Una vez montada,
                se pueden conectar cables comunes a través de una regleta de terminales
                para comunicarse con las dos cabeceras.
